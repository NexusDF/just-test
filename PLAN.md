# План разработки «Три в ряд»

План для оркестрации. Начальник фиксирует правила и контракты, субагенты работают только в своих файлах. После каждой волны начальник принимает результат и возвращает на доработку, если критерий не выполнен.

Код игры пишут субагенты. Начальник до их запуска готовит каркас, типы, GitHub Actions и PWA-конфигурацию.

## Продукт

Браузерная «Три в ряд» на Vue 3 + Vite + TypeScript. Анимации только через GSAP. Поле 8×8. Пять цветов гемов: красный, синий, зелёный, жёлтый, фиолетовый. Сверху одна панель со счётом.

Ход — обмен двух соседних гемов по стороне. Обмен остаётся, только если после него есть линия из 3 и больше по горизонтали или вертикали. Иначе гемы возвращаются на места.

Совпадение снимается, сверху падают гемы, пустые клетки сверху заполняются новыми. Каскады идут до стабильного поля. Новое поле при старте не содержит готовых линий и имеет хотя бы один ход.

Взрывающийся гем появляется, когда игрок собирает линию из 4. Он лежит на поле как отдельный тип клетки. Если обычная линия собирается в клетке по стороне от него, он взрывается и снимает область 3×3 с центром в себе. Взрыв соседнего взрывающегося гема запускает следующий взрыв в той же волне. Линия из 5 снимает всю линию и даёт больший счёт, отдельный спецгем для неё не вводится.

Очки:

- 10 за каждый обычный гем в линии
- 50 за появление взрывающегося гема
- 30 за клетку, снятую взрывом
- множитель каскада ×2, ×3 и далее

Счётчик сверху показывает текущие очки и коротко подсвечивается при начислении.

Частицы: цветные осколки в цвет снятого гема и более яркая вспышка на взрыве. Звуки: обмен, недопустимый ход, снятие линии, падение, взрыв, каскад с повышением тона.

Деплой — GitHub Pages через GitHub Actions. Приложение — PWA: ставится на устройство и после первой загрузки открывается без сети.

## Границы файлов

Общие типы и имена событий фиксирует начальник до запуска субагентов. После этого их меняет только начальник.

| Зона | Кто пишет | Что внутри |
| --- | --- | --- |
| `src/game/` | Логика | Модель поля, ходы, поиск линий, гравитация, взрывы, счёт, каскады. Без Vue, DOM, GSAP и звука |
| `src/assets/gems/` | Ассеты | Шесть SVG: пять цветов и взрывающийся гем, одинаковый размер и силуэт |
| `public/` | Ассеты | Иконки PWA и favicon. Не клетки поля |
| `src/audio/` | Звук | Плеер на Web Audio и набор коротких сигналов по именам событий |
| `src/ui/` | Интерфейс | Vue-компоненты, панель счёта, поле, GSAP-таймлайны, частицы |
| `src/main.ts`, сборка, `.github/workflows/pages.yml`, блок `VitePWA` | Начальник | Каркас Vite, базовый путь, PWA, деплой. Ничего из правил игры |

Логика отдаёт наружу только команды и список событий: `swap`, `reject`, `match`, `explode`, `fall`, `spawn`, `score`. Интерфейс проигрывает их по порядку и не решает, что совпало. Звук слушает те же имена событий и не знает координат. Картинки гемов — файлы с фиксированными именами: `red.svg`, `blue.svg`, `green.svg`, `yellow.svg`, `purple.svg`, `bomb.svg`.

Субагенты не меняют workflow, `base` во Vite и блок `VitePWA`.

## GitHub Pages

Сайт проектный, адрес вида `https://<owner>.github.io/<repo>/`.

Файл `.github/workflows/pages.yml`:

- триггер: push в `main` и ручной запуск
- права: `contents: read`, `pages: write`, `id-token: write`
- concurrency-группа `pages`, предыдущий деплой отменяется
- job сборки на Node 22: checkout, `actions/configure-pages`, `npm ci`, `npm run build`, загрузка каталога `dist` через `actions/upload-pages-artifact`
- `actions/configure-pages` отдаёт `base_path`, он уходит в сборку как `PAGES_BASE`
- job деплоя зависит от сборки, среда `github-pages`, шаг `actions/deploy-pages`

В настройках репозитория источник Pages — GitHub Actions. Это проверяет начальник перед первым прогоном.

Vite `base` равен `PAGES_BASE` со слэшем на конце. Локально, когда переменной нет, `base` равен `/`.

## PWA

Плагин `vite-plugin-pwa`, стратегия `generateSW`, `registerType: 'autoUpdate'`. `scope` и `start_url` плагин берёт из `base`. Отдельно их не дублировать: service worker открывается как `/<repo>/sw.js`.

Манифест:

- имя «Три в ряд», короткое имя «3 в ряд»
- `display: standalone`
- `theme_color` совпадает с `<meta name="theme-color">` в `index.html`
- иконки 192 и 512, плюс maskable 512

В precache попадают `js`, `css`, `html`, `ico`, `png`, `svg`, `webmanifest`. Свой service worker не пишется. Игра на клиенте, отдельного API нет, поэтому после первой загрузки партия идёт без сети.

Иконки установки, их рисует агент ассетов:

- `public/favicon.ico`
- `public/apple-touch-icon.png` (180)
- `public/pwa-192x192.png`
- `public/pwa-512x512.png`
- `public/pwa-512x512-maskable.png`

## Волны

Субагенты одной волны запускаются параллельно. Следующая волна стартует только после приёмки предыдущей.

### Волна 0 — начальник

Каркас Vite + Vue 3 + TypeScript, пустые папки зон, замороженный файл типов и список событий, тестовый раннер для логики. Workflow, `base`, `VitePWA`, мета-тег цвета. Игровых правил нет. Сборка уже даёт `dist` с манифестом и `sw.js`.

### Волна 1 — параллельно

- Логика: движок и тесты на ход, отказ, линию, каскад, появление и взрыв гема, стартовое поле.
- Ассеты: шесть SVG в одном стиле, читаемых на клетке примерно 64×64, плюс пять файлов иконок в `public/`.
- Звук: функции воспроизведения по именам событий, без зависимости от Vue.

### Волна 2 — интерфейс

Поле, перетаскивание или клик по двум клеткам, панель счёта, проигрывание событий через GSAP, частицы. Картинки и звук только потребляются, правила не дублируются. Пути к гемам и регистрация service worker идут через средства Vite и плагина, без зашитого `/`. Во время анимации второй ход не принимается.

### Волна 3 — начальник

Сборка целиком, прогон тестов, проверка в браузере по сценариям приёмки. Замечания уходят адресно тому, чья зона сломана.

## Брифы субагентов

Каждый бриф содержит замороженные типы, список своих файлов, запрет править чужие папки и критерии приёмки своей зоны.

Логика сдаёт движок и тесты. В `src/game/` нет импортов Vue, GSAP и аудио.

Ассеты сдают SVG гемов и иконки PWA. Обычные гемы одного силуэта и разного цвета. Бомба отличима без текста. На тёмном и светлом фоне контур читается. Иконки — PNG указанных размеров, в том же стиле, что и гемы.

Звук сдаёт плеер на Web Audio. У каждого типа события свой сигнал. Повторный вызов не ломает контекст. При запрете автовоспроизведения браузером игра продолжается молча. Vue в этой зоне нет.

Интерфейс сдаёт поле, панель счёта, GSAP и частицы. Он не пересчитывает совпадения и не меняет счёт сам.

## Приёмка

### Логика

Тесты зелёные. Недопустимый ход не меняет поле. Каскад доигрывает до конца. Взрыв 3×3 задевает соседнюю бомбу один раз за волну. Счёт совпадает с формулой. Старт без готовых линий и с хотя бы одним ходом.

### Ассеты

Все шесть SVG на месте, без растра. Пять файлов в `public/` на месте и тех размеров, которые указаны выше.

### Звук

Каждый тип события имеет свой сигнал. Ошибка автовоспроизведения не роняет партию.

### Интерфейс

Проверка в браузере, не по скриншоту:

- клик по двум соседним гемам меняет их местами, недопустимый обмен возвращается
- линия исчезает, гемы падают, сверху приходят новые, счёт растёт
- линия из 4 оставляет бомбу, линия рядом с ней даёт вспышку 3×3
- во время анимации второй ход не принимается
- счётчик сверху виден сразу и обновляется на каскаде
- частицы и звук совпадают с событием и не играют пачкой в конце

### Деплой и PWA

В `dist` есть `manifest.webmanifest`, `sw.js` и `index.html`. Ссылки на скрипты начинаются с `/<repo>/`. В манифесте есть имя, `display: standalone`, иконки 192 и 512, `scope` и `start_url` совпадают с базовым путём, `theme_color` совпадает с мета-тегом.

Поведение проверяется на `vite preview` после production-сборки, не на dev-сервере. Страница ставится как приложение. После первой загрузки повторное открытие с выключенной сетью показывает поле. Повторный деплой подхватывается без кнопки «обновить» за счёт `autoUpdate`.

Workflow принят, если артефакт — именно `dist`, деплой идёт через `actions/deploy-pages`, а в логе Pages есть URL.

Если service worker зарегистрирован от корня домена или иконки не попали в precache, правка возвращается начальнику в конфиг или агенту ассетов в `public/`. Логику поля из-за этого не трогаем.

## Доработка

Если пункт провален, субагент получает только свою зону, цитату критерия, что именно не так, и запрет править чужие папки. После правки начальник проверяет тот же пункт заново и соседние сценарии, которые правка могла задеть. Волна закрыта, когда все пункты её чеклиста пройдены.
